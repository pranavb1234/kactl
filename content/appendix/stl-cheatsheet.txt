```cpp
#include <bits/stdc++.h>

```

## 1. Containers

### vector: dynamic array
```cpp
vector<int> v(n, 0);        // size n, filled with 0
v.push_back(x);  v.pop_back();
v.size(); v.empty(); v.clear();
v.front(); v.back(); v[i];
v.insert(v.begin()+i, x);   // O(n)
v.erase(v.begin()+i);       // O(n)
v.resize(k);  v.assign(n, x);
vector<vector<int>> g(n);   // adjacency list: g[u].push_back(v)
```
Access is O(1) and push_back is amortized O(1).

### pair / tuple
```cpp
pair<int,int> p = {1,2};  p.first; p.second;   // compares lexicographically
auto [a,b] = p;                                // structured binding (C++17)
tuple<int,int,int> t = {1,2,3};  get<0>(t);
```

### string
```cpp
s.size(); s += "ab"; s.substr(pos, len);
s.find("ab");               // returns string::npos if not found
s.push_back('c'); s.pop_back();
reverse(all(s));
stoi(s); stoll(s); to_string(123);
```

### deque: push/pop at both ends O(1)
```cpp
deque<int> d;  d.push_front(x); d.push_back(x);
d.pop_front(); d.pop_back(); d.front(); d.back(); d[i];
```

### stack / queue
```cpp
stack<int> s;  s.push(x); s.top(); s.pop(); s.empty();
queue<int> q;  q.push(x); q.front(); q.back(); q.pop();   // BFS
```

### priority_queue (heap)
```cpp
priority_queue<int> pq;                            // MAX heap
priority_queue<int, vector<int>, greater<int>> pq; // MIN heap
pq.push(x); pq.top(); pq.pop();                    // O(log n)

// Dijkstra
priority_queue<pii, vector<pii>, greater<pii>> pq; // {dist, node}
```

### set / multiset: sorted, O(log n)
```cpp
set<int> s;
s.insert(x); s.erase(x); s.count(x); s.find(x);    // find returns s.end() if absent
s.lower_bound(x);   // first element >= x
s.upper_bound(x);   // first element > x
*s.begin(); *s.rbegin();                           // min / max
// largest element <= x:
auto it = s.upper_bound(x); if(it != s.begin()) --it, cout << *it;
```
- `multiset` allows duplicates. `s.erase(x)` removes **all** copies. To remove one, use `s.erase(s.find(x))`.
- `unordered_set` is O(1) average, but unsorted and can be hacked or slow on bad hashes.

### map / multimap: sorted key-value
```cpp
map<string,int> m;
m[key]++;                   // creates the key with value 0 if absent
m.count(key); m.find(key); m.erase(key);
for(auto &[k,val] : m) ...  // iterates in sorted key order
m.lower_bound(k);
```
`unordered_map` is O(1) average. Avoid `m[key]` just to test existence, since it inserts the key. Use `count` or `find`.

### bitset
```cpp
bitset<1000> b;  b[i]=1; b.set(i); b.reset(i); b.flip(i);
b.count();  b.any(); b.none();
b1 & b2, b1 | b2, b1 << k      // very fast bit DP and sieve
```

## 2. `<algorithm>` (all on ranges `[begin, end)`)

| Function | What it does |
|---|---|
| `sort(all(v))` | O(n log n) ascending |
| `sort(all(v), greater<int>())` | descending |
| `sort(all(v), [](auto&a, auto&b){return a.second < b.second;})` | custom comparator |
| `reverse(all(v))` | reverse |
| `unique(all(v))` | removes adjacent duplicates, returns new end |
| `binary_search(all(v), x)` | true/false, sorted input |
| `lower_bound(all(v), x)` | first element >= x |
| `upper_bound(all(v), x)` | first element > x |
| `*max_element(all(v))` / `*min_element(all(v))` | max / min value |
| `min(a,b)`, `max(a,b)`, `swap(a,b)` | basics |
| `next_permutation(all(v))` | next permutation; returns false after last |
| `fill(all(v), x)` | fill with x |
| `iota(all(v), 0)` | fills 0,1,2,... |
| `accumulate(all(v), 0LL)` | sum (use `0LL` to avoid overflow) |
| `count(all(v), x)` | occurrences of x |
| `find(all(v), x)` | iterator to x, or `end()` |
| `rotate(v.begin(), v.begin()+k, v.end())` | left rotate by k |
| `partial_sum(all(v), p.begin())` | prefix sums |
| `nth_element(v.begin(), v.begin()+k, v.end())` | k-th smallest in O(n) |
| `is_sorted(all(v))` | check sortedness |

### Common idioms
```cpp
// Coordinate compression
sort(all(v)); v.erase(unique(all(v)), v.end());
int id = lower_bound(all(v), x) - v.begin();

// Index of lower_bound
int pos = lower_bound(all(v), x) - v.begin();

// Count of elements in [l, r]
upper_bound(all(v), r) - lower_bound(all(v), l);

// All permutations
sort(all(v)); do { /* use v */ } while(next_permutation(all(v)));

// Sort indices by value
iota(all(idx), 0); sort(all(idx), [&](int a,int b){return v[a]<v[b];});
```

## 3. Numeric and utility

```cpp
__gcd(a,b); gcd(a,b); lcm(a,b);      // gcd/lcm in C++17
abs(x); sqrt(x); pow(a,b);           // pow returns double: don't use it for big integers

__builtin_clz(x); __builtin_ctz(x);  // leading / trailing zeros
INT_MAX; LLONG_MAX; INT_MIN;
const int INF = 1e9; const ll LINF = 1e18;
```

**Fast power mod**
```cpp
ll power(ll a, ll b, ll m){ ll r=1; a%=m; while(b){ if(b&1) r=r*a%m; a=a*a%m; b>>=1;} return r; }
```

## 5. Complexity quick reference

| n | Allowed complexity |
|---|---|
| <= 10 | O(n!) |
| <= 20 | O(2^n * n) |
| <= 500 | O(n^3) |
| <= 5000 | O(n^2) |
| <= 1e5 to 1e6 | O(n log n) |
| <= 1e7 | O(n) |
| >= 1e9 | O(log n) or O(1) |

Roughly 1e8 simple operations per second.

## 6. Common pitfalls (cost people WAs and TLEs)
- Use `ll` when values exceed 2e9, and write `1LL * a * b`.
- `v.size()` is unsigned, so `v.size() - 1` underflows when empty. Cast with `(int)v.size()`.
- `lower_bound` on a `set` should be `s.lower_bound(x)`. `lower_bound(all(s), x)` is O(n).
- `map[]` inserts missing keys.
- `unique` needs a sorted array first, and must be followed by `erase`.
- `memset(a, 0, sizeof a)` is fine for 0 and -1 only. Use `fill` for other values.
- Clear global containers between test cases.
- A `priority_queue` is a max-heap by default.
- Don't use `endl` or `pow()` for integers.
